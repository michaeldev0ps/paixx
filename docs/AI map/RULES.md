# Development Rules

Rule 1

Never install unnecessary packages.

Rule 2

Always keep components modular.

Rule 3

No hardcoded colors.

Use Tailwind config variables.

Rule 4

Never duplicate code.

Rule 5

Every page must score above 95 on Lighthouse.

Rule 6

Use semantic HTML.

Rule 7

Animations should never reduce usability.

Rule 8

Dark mode is the default.

Rule 9

Every commit should be meaningful.

Rule 10

Every feature should be production-ready before merging.
